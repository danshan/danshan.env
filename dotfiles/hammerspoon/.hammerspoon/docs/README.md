# 文档导航

本目录保存 Hammerspoon 配置的长期开发文档. 根 `README.md` 面向日常使用, 本目录面向维护.

- [开发约定](development.md): 模块边界, 修改流程和验证要求.
- [文档规范](standards/documentation.md): 文档路径, 命名, 结构和语言规则.
- [2026-09-15 代码审查](reviews/2026-09-15-upstream-review.md): 上游导入基线, 发现和处理结果.

新文档应放入最窄的主题目录. 仅有一个文件的主题直接放在 `docs/`; Review 放在 `docs/reviews/`; 通用规范放在 `docs/standards/`.
